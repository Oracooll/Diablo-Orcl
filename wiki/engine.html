Engine improvements

What this fork changed in the engine underneath the game: the renderer and text pipeline, asset loading and archives, the save format, the UI framework, input dispatch, the palette, the build and tooling, the test infrastructure, and the instruments that watch it all. Gameplay content - skills, items, monsters, balance, art - is on the other pages. Dates and versions are those of the development report that introduced each change; the file is where to look.

How to read this page. Each row is one improvement: what it is, why it exists, when it landed, and the file that carries it. Most rows came from a bug that shipped first - the "why" column says which. The page was compiled on 2026-09-07 from the 400 development reports and the source tree; it is hand-kept, so a new engine change wants a row here.
