# Short Title

## Context

Why this work happened — the request, the bug, the observation that triggered it. Link back to whatever prompted it if there's a related note.

## What changed

The concrete changes, file by file where useful. Prefer `path/to/file.ext:line` references over vague descriptions.

## Why

The reasoning behind non-obvious choices. Skip this section if "what changed" already makes it obvious.

## Verification

How it was confirmed to work — build output, test results, a screenshot, manual steps taken. If something couldn't be verified, say so explicitly rather than omitting it.

## Not done / deliberately left alone

Anything adjacent that was considered but not changed, and why.
