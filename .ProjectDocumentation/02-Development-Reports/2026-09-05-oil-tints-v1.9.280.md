# Oils in ten colours (v1.9.280)

**Date:** 2026-09-05
**Request:** "how many oils are in this game? we need to have them have distinctive colors, because now they are indistinguishible."

## Count

Ten named oils, all Hellfire's: Accuracy, Mastery, Sharpness, Death, Skill, Blacksmith, Fortitude, Permanence, Hardening, Imperviousness. An eleventh misc id, the generic "Oil" (`IMISC_OILOF`), is a placeholder the drop code rerolls into one of the ten and never reaches a grid.

All eleven rows in `itemdat.cpp` point at one cursor sprite, `ICURS_OIL`: a 28x28 dark-grey glass flask with a small brown stopper. Nothing but the name told them apart.

## What was done

`Source/oracool/oil_tint.{h,cpp}` - `OilTRN(item)` returns a 256-entry palette translation per oil, or nullptr for anything else.

A probe of the sprite (a throwaway test, since replaced by the real one) showed the glass entirely on the grey ramp 243..254 and the stopper on 166..173 - both in the palette half that is identical in town and every dungeon. The table moves the grey ramp onto a coloured ramp at the same relative brightness, lifted three steps towards the light end (six for silver) because the flask is mostly the ramp's dark half. The stopper, the transparent key and pure white stay put.

| Oil | Ramp |
|---|---|
| Accuracy | steel blue (176) |
| Mastery | pure blue (128) |
| Sharpness | red (136) |
| Death | crimson (224) |
| Skill | green (152) |
| Blacksmith | dusty rose (160) |
| Fortitude | yellow (144) |
| Permanence | silver (grey ramp, lifted) |
| Hardening | gold (192) |
| Imperviousness | orange (208) |

The related pairs (Accuracy/Mastery, Sharpness/Death, Hardening/Imperviousness) share a hue family, the greater one on the more saturated ramp.

Draw sites: `cursor.cpp` `DrawItem` (inventory, belt, stash, Levski grid, the held cursor), `shop_grid.cpp` (vendor wares), and `scrollrt.cpp` for the floor, where the tint is composed with the tile's light table because `ClxDrawTRN` takes one table. The floor drop animation is a different sprite; any grey in it recolours the same way.

## Test

`OracoolOilTint.TheTenOilsRecolourTheFlaskTenDifferentWays` - ten non-null tables, key/stopper/white untouched, glass indices land in the shared half, pairwise distinct on the flask's commonest index; and the sprite itself re-read from the archive to confirm it still paints on those two ramps only.

## Not done

No new art. If the user wants painted flasks instead, they go on sheet 3 (`oracool_items.cel`) as ten `ICURS_ORACOOL_OIL_*` ids and the eleven `itemdat.cpp` rows point at them; `OilTRN` then returns nullptr for everything and can be deleted.
