# 2026-10-02 - Audit round 75 (v1.12.323)

**Date:** 2026-10-02. Debug only. 904 tests pass; the Debug `diablo.ini` was unchanged by ctest. Commit b2d892af.

Three read-only auditors ran:
- a regression review of v1.12.322;
- windows, HUD and input (8th pass);
- shops and town NPCs (6th pass).

## Input and windows
- **A button held into the pause** springs back without acting when it is released.
  - Before, releasing it during the pause still ran Sell All, the salvage plates, the workshop and stash controls and the stat buttons. Only the Stonegate and waypoint menus had refused this.
  - The new `ReleaseHeldButtonsWithoutActing` releases everything as if outside it, on entering the pause.
- **A release swallowed by a loading screen** goes through the same helper. Before, the wells, tabs and workshop controls stayed sunk, and the hero sheet ate its next click.
- **The gamepad's right release** lets the Abilities icons and the HUD well go, as the mouse's right release does.
- **Close everything:** it restores chat's hidden event log before closing the log. Before, the log came back after a book closed everything.
- **The HUD menu's Inventory entry** leaves an open shop's backpack alone, as the I key does.

## Shops
- **Sell All** keeps Imbuement Shards. They are drop-only, like the Signets and Sealed Maps it already kept.
- **Wirt's Shop tab, keyboard Enter:** it now goes through the grid shop's own handler. The old `BoyBuyEnter` priced the always-empty `boyitem`, so it never refused. It could not be reached in play, and it is removed.

## Regression review of v1.12.322
- **A Zod-only ethereal host** is still picked up as Free the Sockets' target, so the recipe says why it refuses ("Zod is bound for good"). It still stays off the auto-pick.
- **A trimmed Tempering shard** takes its overpaid durability off the current durability too, not only off the maximum.
