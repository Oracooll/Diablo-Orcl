# 2026-10-01 - Audit round 52 (v1.12.288)

**Date:** 2026-10-01. Debug only. 899 tests pass; the Debug `diablo.ini` was unchanged by ctest.

**Tracks:**
- the save pipeline and the hero file (4th pass);
- Sorcerer, Rogue and Monk actives (7th pass).

## Fixed

### Save pipeline
- **Corpses on revisited floors, for real this time.** `LoadCorpseTable` checked `IsValid()` after reading the tail. That asks for one byte beyond the cursor, and the tail is the last thing in the level file, so every complete table was thrown away. The round 47 fix (v1.12.280) never took effect in play. The check now runs before the records are read: `IsValid(count x 29)`.
- **The left-button hotkey** in the hotkeys file was written but never read. Its check counted the whole file again from the cursor.
- **`SaveHelper::Skip`** is bounded, as `WriteBytes` is. It used to zero memory past the buffer before the destructor noticed.
- **Inventory tabs** need a whole item record per item, not one byte of it.
- **Corrupt corpse records** whose monster type is out of range are dropped.

### Actives
- **Movement skills (`TeleportTo`):**
  - a landing more than a tile past the aim's own distance is refused;
  - every refusal says ICantDoThat for Vault, Leaping Crane, Shoulder Gate, Ride the Lightning, Shadow Step and Heaven's Descent;
  - Turning Pike's side-step stays quiet.
- **Storm Crucible:**
  - strikes and draws the true straight line between its two conductors (`TilesBetween`);
  - a second conductor on the first one's tile is refused.
- **Firestorm** throws its fireballs from the tile it was cast on.
- **Funeral Star:** recasting it ends the old star's art.
- **Shiver Armor:** its bolt takes Frostbite's bonus.

## Open, for the user
- **Order of Strength and passives.** Skill blows (`WeaponBlow`, `FullBlow`) let the damage passives multiply the Strength part, while the plain swing adds Strength after them. Since Strength became a percentage of the weapon, a skill's side blow can out-hit the swing. This is the same decision as round 51's question 3: pool Strength with skill +% the Diablo II way, or keep Strength outside the multipliers everywhere.
- **No-target fizzles.** About 25 skills fizzle silently when there is no target (unpaid). Should they say ICantDoThat too?
- **A failed level save** (full disk, locked file) brings back the previous visit's snapshot of that floor, which can duplicate picked-up items. Needs a save-attempt check in `pfile_save_level`; not changed this round.
- **Save buffer headroom:** `SaveLevel` has about 3.9 KB left in the worst case, so a ~31-byte item-format growth would overflow it. Size the buffer from the constants before the next item-format bump.
