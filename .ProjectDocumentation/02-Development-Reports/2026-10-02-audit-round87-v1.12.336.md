# 2026-10-02 - Audit round 87 (v1.12.336)

**Date:** 2026-10-02. Debug only. 904 tests pass; the Debug `diablo.ini` was unchanged by ctest. Commit f3e858a4.

Three read-only auditors ran:
- a regression review of v1.12.334-335 (item format 17);

## Fixed
- **Oiled uniques:** an oiled unique no longer shows its oil to-hit twice. Its `PrintItemPower` to-hit rows printed the total, which includes the oils' share. That share now has its own line, so those rows leave it out.
  - Format 17 itself checked clean:
    - The hero's items round-trip through `heroitems` (`SaveItem`/`LoadItemData`, the whole stored item copied over the packed one).
    - Every rebuild zeroes the field and then reapplies it.
    - The size table matches.
- **Blood is Power:** it counts the life the blow actually took, not the overkill. Before, a 300-point blow at 20 life paid 25 Essence.
- **Aberrant Animator and the Iron Golem:** they now say "melee blows". Only melee reaches the return.
- **Doc comment:** `BoneStrike`'s comment is back above it. Round 79 had left it above `BoneWallSegment`.

## The gamepad package (open, with exact fixes)
The round-75 open item "no pad on pages 2-10 or the belt", described precisely. The fixes are not built, because pad input cannot be verified here without a controller and screenshots.

1. **Backpack pages 2-10**
   - **Problem:** LB/RB turn pages only in the stash; with the backpack open they drink potions. The D-pad never lands on a tab. X does nothing on pages 2-10, because `pcursinvitem` is -1 there.
   - **Fix:** in `PressControllerButton`, an `invflag` branch where LB/RB step `ActiveInventoryTab`, skipping locked pages. `PerformSpellAction` should also accept `pcursinvtabitem`.
2. **Belt**
   - **Problem:** the D-pad uses vanilla's `BeltRect` coordinates, while every hit-test uses `oracool::GetBeltSlotRect`. Moving down maps columns 0-7 onto SpdList 0-7, which includes Menu, Portal, Run and the hidden slot.
   - **Fix:**
     - `GetSlotCoord` should use `GetBeltSlotRect`.
     - Moving down should map to slots 1-4.
     - Left/right should skip slots that are not real belt items.
3. **A with the backpack open**
   - **Problem:** with the backpack open, A over the Cube, the workshop or the runeword book does nothing. The `invflag` block returns before the floating-window branch.
   - **Fix:** move that branch above it.
4. **Class tree**
   - **Problem:** with it open, B becomes Space and closes everything, and Y becomes Return and opens the chat line. No button invests a point or binds a skill.
   - **Fix:** drop Y→Return, and add `if (sbookflag) ClickUiAtCursor()` in `PerformPrimaryAction`.
5. **Y on pages 2-10**
   - **Problem:** it skips page 1's checks. A monster-targeted scroll fires at the tile ahead and is used up.
6. **Pad quick-spell menu**
   - **Problem:** it ignores aura and left-button F-key bindings.
   - **Fix:** use `HandleAbilityFKey`.
