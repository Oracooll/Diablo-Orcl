# 2026-10-05 - Audit round 104 (v1.12.388)

**Date:** 2026-10-05. Debug only. All 948 tests pass. The Debug `diablo.ini` was unchanged by ctest (md5 b3392ce4).

**Tracks (two):** a regression review of v1.12.387, and rift and boss state across quit, crash, autosave and a portal out.

## Fixed: keystones
1. **The next Guardian Keystone was lost on a quit or crash before its pickup (P2).** The kill cleared the owed tier, but the reward keystone (tier +1, or +3 for a fast run) was only a floor item, and the rift's state goes with the session. Dying, portalling out or walking out with a full pack, then quitting, lost the ladder; "it waits in the rift" was false across a quit.
   - **Owed from the kill:** the kill now owes the next tier. `RefundOwedGuardianKeystone` gives it back next game.
   - **Settled on pickup:** the debt clears when no keystone is left on the rift's floor (checked each tick), or when `CarryFloorKeystonesHome` carries them all. So a picked-up keystone is never also refunded.
   - **Refund message:** it now reads "The keystone your last Guardian Rift owed you comes back".
2. **A refund with no room anywhere dropped the keystone on the town floor and forgot it (P3).** No new game keeps that floor. It now stays owed, with a red note to make room.
3. **A rift floor rebuilt after a failed level save (P3).** The boss's run state (conjured copies, raised dead) named the lost floor's slots, so an expiring entry could despawn an innocent monster. The rebuild now resets it.

## Fixed: regressions in round 103's own fixes
4. **The guardian's spot search, two corrections:**
   - **Walk test:** reachability now uses the hero's own `IsTileWalkable(ignoreDoors)` instead of `!IsTileSolid`, which passed crosses and sarcophagi.
   - **Cost:** the sighted pass stops at radius 20 instead of paying a sight line and a path for tiles that can't be reached.
5. **The rift HUD name flickered (P3).** It flipped between the name and "the boss" as the proportional clock digits ticked. It now measures against the widest clock.
6. **Test hygiene.** The every-row floor test now sets `currlevel` as the game does for a set level, and restores `ActiveMonsterCount`.

## Checked and fine
- **A new game never starts on a set level.**
- **The spent-keystone refund is crash-safe.**
- **An autosave never captures a level, so no live boss or copy is ever saved.**
- **A portal-out round trip keeps the boss's scaled stats and flags (MFLAG_KNOCKBACK included).**
