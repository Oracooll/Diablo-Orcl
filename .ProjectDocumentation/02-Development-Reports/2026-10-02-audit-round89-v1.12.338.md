# 2026-10-02 - Audit round 89 (v1.12.338)

**Date:** 2026-10-02. Debug only. 904 tests pass; the Debug `diablo.ini` was unchanged by ctest. Commit 927d693e.

Four read-only auditors ran:
- a regression review of v1.12.337, which was clean (one translation wrap);
- the class tree's investment logic;
- the grid shops' click flows (2nd pass);
- the debug commands and `_DEBUG` guards.

## Shops
- **Right click with an item in hand:** it no longer sells or repairs that item. Only a left click is a drop.
  - Before, right-clicking a stock item while holding a sword sold the sword.
  - On the Repair plate, the same click paid for a repair.
- **Repair All:** it now picks, on each pass, the dearest repair the hero can afford. Before, one unaffordable item at the top stopped ten cheap repairs.
- **Sell All's hint:** it now lists what Sell All keeps: charms, shards, maps, signets, quest items and socketed items.
- **Checked and clean:**
  - stale indexes between press and release;
  - buying from a tab that is not shown;
  - keyboard navigation;
  - buyback into a full pack;
  - the sell hammer;
  - Wirt's gamble preview;
  - Refresh Until's bounds.

## Class tree
- **Unbuilt rows:** a right click now refunds points left in an unbuilt row. Before, only Adria's paid respec could return them.
- **Checked and clean:**
  - Ctrl and Shift batches re-check the pool, the rank cap and the level gate on every point.
  - Refunds clamp.
  - A refund or respec clears lost bindings on both readied buttons and all 12 F-keys.
  - Item +skills cannot make a 0-point skill usable.
  - No cross-class bindings.
  - Statics are reset.
- **Press/release:** the tree acts on the press, which is part of the parked press/release pass.

## Debug builds
- **Release is clean of debug code:** no debug code reaches it, and god-mode hooks act only while god mode is on.
- **`iteminfo`:** it uses the proper accessors. A worn slot had read `InvList[-13]`, and pages 2-10 showed page 1's item.
- **`givexp`:** it caps at the levels left. `givexp 100000000` had queued a hundred million packets in one frame.
- **`changehp` and `changemp`:** they clamp, so the `* 64` cannot overflow and mana stays within bounds.
- **`spawn` and `spawnu`:** they refuse a full monster-type table.
- **God mode:** it ends with the game. It had carried silently into the next New Game.

## For the user
- **No chat line in Release single-player:** `IsChatAvailable` is true only in Debug or multiplayer. So in a Release build, Enter opens nothing and `/dev` notes cannot be typed. `dev_notes.cpp` has a Release branch written for it.
  - Fixing it is one line, but it changes Release behaviour: Enter would open the chat line.
