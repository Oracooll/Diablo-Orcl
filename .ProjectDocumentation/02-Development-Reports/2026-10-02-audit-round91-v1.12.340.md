# 2026-10-02 - Audit round 91 (v1.12.340)

**Date:** 2026-10-02. Debug only. 904 tests pass; the Debug `diablo.ini` was unchanged by ctest. Commit 999981e1.

Four read-only auditors ran:
- a regression review of v1.12.339;
- the waypoint list and the Rift Monument menu;

- autosave, the event log, dev notes and telemetry.

## User decision
- **Chat line in Release:** it is now available in single-player Release builds (user, 2026-10-02: "I want /dev command and functionality in release versions").
  - Release `/dev` notes go to `development.md` in the save folder (PrefPath), as `dev_notes.cpp` already wrote for Release.
  - Debug notes still go to the repo's file.
  - The debug commands stay compiled out of Release.

## Fixed
- **Autosave after bulk moves:** equipment changes, drops and stash moves now save once, two seconds after the last move.
  - Before, forty Ctrl-clicks into the stash wrote the hero and the stash forty times on the main thread.
  - Kills, pickups, level changes, purchases and exit keep their own timing.
- **Telemetry file size:** `balance_telemetry.csv` rotates to `.old.csv` past 16 MB. It is on by default and had no cap.
- **Waypoint travel with an item in hand:** now refused, as rift entry already does.
- **Regression of v1.12.339:**
  - The F-key re-type now skips a Scroll binding whose stack is on the cursor. Sorting the stack away had re-typed the binding to the spell for good.
  - Debug `spawn` now clears the reused slot's `minionOnly`.
- **Unbuilt (next build):** debug set pieces clamp their item level to 64.

## For the user

  - the Lost Cartographer's 4/4 fast hit recovery (already on its boots);
