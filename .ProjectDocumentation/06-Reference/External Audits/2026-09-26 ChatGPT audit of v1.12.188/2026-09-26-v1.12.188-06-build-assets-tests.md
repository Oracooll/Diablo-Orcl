## Reproducing the external probes

The evidence folder contains source, builder and logs, not a patched repository. The builder reads the existing Debug `build.ninja` to reuse compiler definitions/includes and import libraries. On this machine, copy the two probe source/builder files into a writable scratch directory, run `node audit-v188-build-probes.cjs`, put `C:\Diablo Orcl\x64-Debug` on `PATH`, then run the resulting probe executable. Its nonzero exit is expected until the defects are fixed. The source currently uses the original audit scratch directory for its isolated preferences path; adjust that path for a different machine.

The stash probe takes roughly 45 seconds in this Debug build. Do not point any new session/save regression at a player's real save folder. The retained production probes do not save a hero or stash.
