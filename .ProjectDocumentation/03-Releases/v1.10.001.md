Windows x64 Release build of Diablo Orcl (formerly "Diablo Orcl V1 — Oracool Edition").

The 1.9 line ran to 318 builds after the last release (v1.9.90); this is the milestone that closes it. The package is the same shape as before: the binary, its libraries, two archives (`oracool.mpq` for this fork's own art and data, `devilutionx.mpq` for the engine's) and a README. You supply Blizzard's archives yourself, as the README explains.

## What changed since v1.9.90

**The whole interface, again.** A stone HUD with sunken orb wells and a joined belt; the belt buttons, the burger menu's eight entries and the inventory tabs drawn as vanilla-style glyphs (the tabs are chests now, lid down or lid raised); every side panel on one painted 340x720 canvas; Levski's Roar, the runeword book and the recipe book on painted stone frames; all 257 class skills with their own glyphs; a silhouette for every class behind the equipment slots.

**Skills.** The six class trees are packed from the left into their level rows, active skills cap at level 30 (only passives reach 36), the Paladin's duplicate Holy Bolt is gone, and every tree skill above spell id 63 now actually has a rank at the mechanics - Frozen Orb, the cold armours, the Rogue's arrows, the class melee skills, the warcries and songs had been reporting rank 0 however many points were spent.

**Items.** Stack placement is all-or-nothing (a merge that could not complete used to duplicate units); an item you cannot equip shows the unmet requirement in red; every fresh drop - chests, racks, corpses, barrels, Find Item - gets the same Magic Find, socket and ethereal rolls a monster drop gets; runewords form only on plain hosts; socket data beyond an item's count is discarded on load.

**Under the hood.** An external multi-audit's nine findings all closed, with regression tests; the test suite is fully green (683 cases) and each test binary also runs whole, shuffled, three times; the level-3 golden map that had failed for weeks was a quest-default mismatch, not the generator; 5.5 MB of art nothing loaded left the archive.

## Note on saves

**Save compatibility is not maintained between versions.** A character from an earlier release may fail to load or lose items. Start a new character.
